## 残余风险与边界

- 这是个人本机产品的明确选择：任务、run 和工具回放结果明文存储；日志、Langfuse 与飞书结果卡仍不记录完整 Prompt、command、console、凭据或原始资源 ID。
- 到点的 Script 以 bot 当前 OS 用户执行用户保存的 command。这是产品能力，不扩展为多用户授权、管理员审批、远程执行或网络隔离；这些需求如出现，必须另开 Story。
- Cron、MySQL 领取、Worker FIFO、静默/非静默和拒绝后不重发均已有测试与本次实际非静默 L4。未来改动 dynamic tool 参数或 run 状态机时，必须同时执行新的 catalog 真实验收和 immediate-consumer 并发测试。
