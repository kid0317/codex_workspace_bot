## 重要项

- 拆开 daemon absent/version error/start timeout/proxy EOF/initialize error/restart 再失败/并发 boot/仅关闭 proxy 的启动矩阵（`S03-AT-02a~02f`）。
- 锁定 generated schema version/hash、已知 fixture 与未知 notification 的生成规则；usage 不在 schema 时明确兼容 fixture。
- `S03-AT-08b` 覆盖 response 前/后、重复、不匹配、timeout 后 event，断言 DB/card 一次终态。
- `S03-AT-07b` 注入 token、Authorization、正文、模型输出、workspace、stack，验证 slog、JSONL、MySQL、Feishu 都不出现。
- `/readyz` 当前只回 receiver snapshot（[main](../../../cmd/server/main.go:106)）；必须验证 App Server ready 组合状态、启动顺序和连接失效可见性。
- `go test -race` 应包含 runtime Close、late event、2 channel 多 Batch，并执行重复计数；同时运行 fake 协议集成与显式真实 App Server tag gate。
