# S03 方案独立评审汇总

> **评审对象**：[S03 真实 Codex App Server 流式调试接入](../../story/S03-真实Codex-App-Server流式调试接入-设计.md)  
> **评审轮次**：2026-07-11，三位彼此独立的只读 reviewer  
> **当前结论**：**通过 blocker-only 复审；可进入 Ready 和实现。**初始拒绝结论保留在下文作为历史评审记录；这不代表 Delivered，真实 L3/L4 与实现验收仍是后续硬门槛。

> **2026-07-11 用户裁决回写**：B1 选择 bot-owned stdio child；B2 选择个人本地 `all` ingress，不实现 Allow list；B3、B4 按评审意见补入 S03 的 collector 状态机与 Thread CAS；B5 收窄为同 ID 的通用 JSON-RPC `-32001` 拒绝器，不提前实现审批矩阵；B6 不增加 App Server readiness HTTP 门禁。上面的初始评审结论保留为历史记录；S03 仍为 Draft，待实现及仅阻塞项复审。

> **2026-07-11 补充裁决**：S03 的个人本地 `debug` 直接逐行保存所有 server→client 原始 JSON-RPC event，以确认每种真实 event 的完整内容；不做脱敏、hash、留存或访问控制设计。该原始日志不进入飞书、MySQL 或 Langfuse，测试结束后切回 `info`。

> **2026-07-11 二次设计回写**：`turn/start` response 返回的 `turn.id` 是 collector 唯一绑定依据；response 前的 notification 只暂存，30 秒未响应不猜测归属而关闭 generation。child 退出为该 generation 创建一个 replacement；仅 replacement startup/initialize 连续失败时进入 `app_server_unavailable`，成功 initialize 后重置失败链，之后新的 exit 可再次恢复。`-32001` server request 仅在带已绑定 route 时失败所属 attempt，不关闭健康 child。debug JSONL 由唯一 reader 在 dispatch 前 `Write+Sync` 到独立按进程命名的文件；写入失败即终止该 generation，避免静默漏 event。

> **2026-07-11 三次设计回写**：debug 证据分为逐行完整 raw 文件和同序号的 timeline 索引文件。timeline 明确记录顺序/时间、generation、JSON-RPC 类别与 method/ID、App/Channel/ChatGroup/attempt、Thread/Turn/Item 与路由结果；按任一维度过滤、按 `seq` 排序即可拉出完整 event 时间线。raw 或 timeline 任一写入失败都终止该 generation，避免原文与时间线不一致。

> **2026-07-11 四次设计回写**：为避免“dispatch 前写索引”与“同一行记录 dispatch 结果”的不可回写矛盾，debug 证据改为 raw + event + outcome：raw/event 在 dispatch 前以同一 `seq` 落盘，outcome 在 dispatch 后追加并以 `seq` join。p2p Worker 调度键明确为 `sender_open_id`，ChatGroup 仍以事件 `chat_id` 持久化；Story List 已去除已废弃的 App Server 复用描述。

> **2026-07-11 blocker-only 复审**：技术协议复审与质量/交付复审均通过。确认 group Worker 以 `chat_id` 调度、p2p Worker 以 `sender_open_id` 调度、ChatGroup 始终按事件 `chat_id` 持久化；确认 raw/event/outcome 的 `seq` 契约可实现，Story List 已与 bot-owned stdio child 一致。无剩余设计 blocker，可进入 Ready；实现必须继续满足 AT-00 至 AT-13、L3/L4 和 DoD。

## 3. XiaoPaw 可采纳与不可采纳的经验

| 类别 | 结论 |
|---|---|
| 可采纳 | readiness 不能只看 HTTP alive；流断无 terminal 必失败；真实验收同时保存状态、事件、DB 与用户可见输出；production review 要把 cold start、session reuse、interrupt、observe failure 作为独立负向路径。 |
| 不可采纳 | FC Session、Redis lease、NAS、responses proxy、按 sandbox 私有 App Server、per-turn WebSocket、SSE `process_delta` 压缩、原始 debug/SSE 内容。 |
| 明确禁止 | 直接拷贝 XiaoPaw `_run_codex_turn`：它没有共享连接 response correlation、server request response、未知通知观察和 S03 的 resume fallback/CAS。 |
