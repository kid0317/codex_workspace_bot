# S05.1 Document Owner Transfer Implementation Plan

**Goal:** When the Bot creates a docx through `feishu.doc_create_and_announce`, transfer ownership of that one document to the exact Feishu sender who caused the active Turn, without allowing model parameters or group reply targets to select an owner.

**Architecture:** Preserve ingress `sender_open_id` only in `worker.ActorPrincipal`; batches form an Actor boundary. `cmd/server` derives a fail-closed `feishuaction.Route.OwnerOpenID`. The action layer accepts no owner parameter from Codex and passes the trusted owner to the Feishu adapter. The adapter calls the generated Drive `permission_member.transfer_owner` API immediately after docx creation and returns a redacted outcome without changing the existing create/announce success semantics.
