# 归档文档说明

本目录保存历史过程材料。它们可用于追溯设计取舍和验收证据，但不是开源读者理解当前项目的主入口。

| 目录 | 内容 |
|---|---|
| `story-retrospectives/` | 已完成 Story 的全过程复盘。 |
| `story-evidence/` | 本地集成验证记录、事件时间线和脱敏证据摘要。 |
| `story-reviews/` | 独立评审、整改复审和 Delivered 审计报告。 |
| `superseded/` | 已被后续设计替代的旧 Story 设计。 |
| `agent-plans/` | agent 执行计划，保留为维护记录。 |
| `agent-specs/` | agent 生成的临时规格文档，保留为维护记录。 |

归档文档可能引用移动前的旧路径。若用于继续开发，应先对照当前 [Story List](../story/STORY_LIST.md)、当前代码和最新 README 重新核验。
